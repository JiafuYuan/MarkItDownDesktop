# MarkItDownDesktop

Windows desktop interface for MarkItDown. Drag files into the window, or drop files directly on `MarkItDownDesktop.exe`, then choose an output folder and start the conversion.

## Build

Place the conversion engine at `outputs\markitdown.exe`, then run:

```powershell
.\build_desktop.ps1
```

The self-contained desktop application is written to `outputs\MarkItDownDesktop`.
